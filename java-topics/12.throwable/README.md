# `Error` and `Exception`

Anything that can be thrown must extend from `Throwable` class.

Usually we do not need to catch `Error` as they are not recoverable (the program will crash and there is nothing you can do) ie `OutOfMemoryError`. 

## Unchecked and checked `Exception`

- checked exceptions are checked by the compiler
- unchecked ones are subclasses of `RunTimeException`
